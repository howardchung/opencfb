# opencfb

An open source project for exploring American college football data.

# Quickstart

- `npm install`
- `npm start`: Runs the React UI
- This project uses [sql.js-httpvfs](https://github.com/phiresky/sql.js-httpvfs) to fetch data from a static SQLite DB, which we rebuild daily with a TypeScript script.
- To build it yourself, run `npm run build:data`

# Tech

- React
- Node.js
- TypeScript
- SQLite
